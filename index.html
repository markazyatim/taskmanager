Cara Membuat Widget Menempel di Desktop Windows (Electron.js)

Agar tampilan web (Opsi 3) bisa **menempel permanen di wallpaper desktop** tanpa window frame, tanpa tombol minimize/close, dan bisa mengirim notifikasi bawaan Windows, gunakan skrip **Electron.js** di bawah ini pada laptop karyawan.

main.js (Konfigurasi Desktop Framing) 
// main.js - Electron Main Process
const { app, BrowserWindow, Notification } = require('electron');
const path = require('path');

let mainWindow;

function createWindow() {
    mainWindow = new BrowserWindow({
        width: 400,
        height: 600,
        x: 50, // Posisi di desktop (Kiri)
        y: 100,
        frame: false,            // Hilangkan border & tombol close/minimize
        transparent: true,        // Membuat background transparan (Glassmorphism)
        resizable: false,
        skipTaskbar: true,       // Tidak muncul di Taskbar Windows
        type: 'desktop',         // Menempel di latar desktop
        webPreferences: {
            nodeIntegration: true,
            contextIsolation: false
        }
    });

    // Muat aplikasi web widget Anda (misal hosted di Vercel/Firebase atau local file)
    mainWindow.loadURL('https://tugas-karyawan-app.web.app');

    // Menjaga agar widget selalu di lapisan bawah wallpaper (Desktop Level)
    mainWindow.setAlwaysOnTop(false);
}

// Fungsi Pemicu Notifikasi Asli Windows 11
function showWindowsNotification(title, body) {
    if (Notification.isSupported()) {
        new Notification({
            title: title || 'Tugas Baru Diterima!',
            body: body || 'Ada instruksi baru dari atasan Anda.',
            icon: path.join(__dirname, 'icon.png'), // Opsional icon
            silent: false // Menghasilkan suara notifikasi Windows
        }).show();
    }
}

app.whenReady().then(createWindow);

Langkah Menjalankan di Laptop Karyawan:

  1. Install Node.js di laptop karyawan.
  2. Buat folder baru (misal: task-widget), lalu jalankan npm init -y di terminal.
  3. Install Electron: npm install electron --save-dev.
  4. Simpan skrip di atas sebagai main.js.
  5. Jalankan widget: npx electron .. Widget akan langsung melayang transparan di atas wallpaper Windows!
